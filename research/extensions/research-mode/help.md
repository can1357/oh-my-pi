Your research workspace

This workspace finds, screens, and organizes papers for a literature review, and
keeps a PRISMA-ready record of every decision you make along the way.

Where to start

  Starting fresh, with only a question         type  /scope
  You already exported records from a search   type  /import
  You just want one quick end-to-end pass      type  /litreview

Everything you can type

  command        what it does                                              when you'd use it
  -------------  --------------------------------------------------------  ----------------------------------
  /scope         Turns a fuzzy question into a written scope with the       First step of a new review
                 inclusion and exclusion rules you will screen against
  /databases     Recommends which databases to search and what each one     Before you run any search
                 misses
  /searchstring  Writes ready-to-paste search strings, one per database     When you search the databases
                                                                            yourself
  /find          Runs the searches this harness can run itself: arXiv,      To collect candidates without
                 OpenAlex, and your own PDF folder                          leaving this window
  /import        Loads RIS, BibTeX, CSV or JSONL exports into the review    You downloaded records elsewhere
  /dedupe        Marks the same paper found twice, keeping one copy         Right after importing several
                                                                            databases
  /screen        Walks the unscreened records and records include or        The title-and-abstract pass
                 exclude with a reason for each
  /fulltext      Hunts down the full text of the papers that passed         After screening, before reading
  /review        Writes a cited synthesis of the papers you included        When the included set is settled
  /graph         Files included papers into your paper graph and draws      To see how the literature connects
                 the neighbourhood around them
  /prisma        Shows the PRISMA-ScR counts and flow diagram               For the methods section, any time
  /export        Writes your records back out as RIS or BibTeX              To move into Covidence, Zotero or
                                                                            EndNote
  /litreview     Runs the whole pipeline once: find, screen, fetch,         A quick first pass on a new topic
                 synthesize, file into the graph

You can also just type sentences

  You never have to remember a command. Plain requests work too, for example:
  "screen the first 10 records against my criteria". After every command the
  assistant tells you what it did and offers the next step, so you can stay in
  plain words the whole way through.

The bar at the bottom of the screen shows your active project and how far the
title-and-abstract screening has got.

Run 'research doctor' in a terminal if something looks broken.
