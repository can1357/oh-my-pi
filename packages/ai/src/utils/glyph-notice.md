Some content in this session contains icon characters (private-use Unicode, e.g. nerd font glyphs) that cannot be shown to you directly. Each such character appears as an opaque token like ⟦Ue0a0⟧ — one token is exactly one character. When copying, moving, or preserving surrounding text, copy each token byte-for-byte. Never invent tokens, alter their hex digits, or expand them into anything else. Writing a token in tool arguments writes the original character. To write the literal text ⟦Ue0a0⟧ rather than the character, escape it as ⟦E⟧Ue0a0⟧.
