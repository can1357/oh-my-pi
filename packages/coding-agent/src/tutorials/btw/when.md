Reach for `/btw` when a quick question comes up mid-turn and the answer is in what omp has already seen. It answers from the session context, uses no tools, and stays out of the main transcript.
Not for questions that need files read or commands run: /btw cannot do either.
To change what omp is doing, type a normal message and press Enter while it runs: that steers the live turn.
Ctrl+Enter (or Ctrl+Q) queues a message for after the turn instead.
`/tan <work>` hands tangential work that needs tools or edits to a background agent.
Just wait when the question depends on the turn's result. If a side answer turns into real work, `b` on a finished answer (once omp is idle) branches it into its own session.
