Request a cooperative restart of this session — recycle it to pick up host-staged changes that a live `refresh` cannot reach, while continuing the same conversation from the durable session file.

This tool exists only when the SDK embedder that started this session wired an `onRestartRequested` lifecycle callback; a default `omp` CLI session does not offer it, and if you cannot see it, restart is not available here. When present, restart recycles ONLY this session (same loaded engine code): the host quiesces the running turn, flushes the transcript to disk, disposes the session, then re-opens it from its file. Use it when new *extensions*, project context (`AGENTS.md`), slash commands, prompt templates, the tool roster, or the model/provider registry changed on disk — surfaces frozen at session start that `refresh` (skills/rules/settings/MCP only) does not re-read. Picking up a new engine *binary* is a host-process operation, not this tool.

This tool returns immediately with an acknowledgement; the actual recycle runs after the current turn settles. A refusal before teardown (another turn's input is still queued, or restart is unavailable in this session) is reported back to you and leaves the session untouched — you may retry once quiet. Once teardown begins the conversation resumes in the recycled session; recovery is via the durable session file.
