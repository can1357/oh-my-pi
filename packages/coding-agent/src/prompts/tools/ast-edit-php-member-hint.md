PHP member patterns only parse inside a class body. Wrap both `pat` and `out` in `class $CLS { … }`, reusing `$CLS` in `out` (`$_` is not captured there). That wrapper matches only a class whose body is that one member and that has no `extends`, `implements`, `final`, `abstract` or attributes. For any other class, locate the member with `ast_grep` or `read` and change it with `edit`.
