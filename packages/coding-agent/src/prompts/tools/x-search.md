Search X (Twitter) posts, profiles, and threads via xAI `x_search`. Read-only: current discussion, reactions, and claims on public X — not the open web (`web_search`), and not posting, liking, or DMs.

`from_date`/`to_date` are YYYY-MM-DD. `allowed_x_handles` and `excluded_x_handles` are mutually exclusive (max 20; `@` optional). `after:`/`before:` in the query map to those dates. Needs an xAI credential (SuperGrok OAuth or `XAI_API_KEY`). API-key calls are billed per fetched post.
