`proc://`: jobs, agents, and services; `proc://<id>` status/output; write sends stdin to services only (empty = Enter); `proc://<id>/kill` cancels/stops jobs, agents, and services, omit `content`; `proc://<id>/mode`: `persist`|`session`|`detached` (services only); start long-lived work as a named service when it needs stdin or lifetime controls; `proc://<id>/streams` lists a bash job's pipes, `proc://<id>/streams/<n>` reads what crossed pipe `n` so far (live under `| tail`/`| grep`; never rerun to see it). Job records are process-local and may be evicted after completion, job IDs can differ from agent IDs, and idle/parked agents need no `proc://` entry; check `agent://<id>` or `history://<id>` for a known agent's retained output or transcript before assuming it was lost.
