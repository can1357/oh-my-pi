`ssh://host/<path>`: remote UTF-8 file/dir (max 1 MiB) for read/write/grep; edit updates existing regular files (no symlinks/create/delete/move); hashline reads supply snapshot tags. Bare lists hosts. `/~/path` and `/~` use the connected remote account's HOME, not local HOME; `/~user` is unsupported, `/%7E/` is literal. Encode `:` `?` `#` as %3A %3F %23. Needs verified POSIX shell; else bash remote SSH or sshfs.
