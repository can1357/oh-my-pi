[Indentation: frames do not print whitespace, so each line's leading indentation is drawn as a bracket after its line-number prefix (`N:`, `N|`, `N-M:`, `N-M|`), or at line start: `[»3]` = 3 tab characters, `[·8]` = 8 spaces, `[»1·2]` = 1 tab then 2 spaces, `[0]` = no indentation (marks a line whose own text starts with such a bracket, or with a number and `:`/`|` before one). Only the first bracket after the prefix is indentation; lines without one have none. Write real tabs/spaces in edits, never the bracket.]
