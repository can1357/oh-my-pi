When a lesson is a durable observation rather than a procedure — a project convention, a non-obvious fix, a user preference — record it with `learn`, which writes to the configured long-term memory backend and/or Obsidian learning vault. Vault notes label capture separately from evaluation and promotion. `learn` can also mint or enhance a managed skill in the same call when the procedure has already been verified; it does not automatically evaluate or promote an evolutionary candidate.
