The state is a user's request to a coding agent. Choose the reasoning effort this turn needs, judging inherent task difficulty rather than phrasing politeness or verbosity. A `<complexity>` field, when present, is the delegating agent's rationale for the task's difficulty; it has seen context the request may omit, so weigh it as strong evidence. If torn between levels, choose the lower one{{#if withMax}}, except between xhigh and max: a request meeting the max conditions takes max{{/if}}.
