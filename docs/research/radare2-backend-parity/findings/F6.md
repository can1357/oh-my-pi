## Claims

### 1. Address expressions, `@`, numeric bases

- Command grammar has a temporary-offset field `@`, a foreach field `@@`, and `;` command separator; `p8 10 @ 0x4010` and `f patata @ 0x10` execute at a temporary offset; `p8 20 @@ hit0_*` is foreach over matching flags — https://book.rada.re/commandline/intro.html — 2026-11-17 — primary.
- Expressions are 64-bit RNum values; ops `+ - * / % & | ^ >> <<`; `?` evaluates (e.g. `?vi 0x8048000+34`); `|` must be quoted to avoid shell pipe — https://book.rada.re/first_steps/expressions.html — 2026-11-17 — primary.
- Accepted numeric forms per book: `0x033` hex, `3334` decimal, `sym.fo` resolves flag offset, `10K` = 10*1024, `10M` = 10*1024*1024; variables `$$` (current virtual seek), `$l` opcode length, `$s` file size, `$j` jump addr, `$f` fail addr, `$m` memory ref, `$b` block size — https://book.rada.re/first_steps/expressions.html — 2026-11-17 — primary.
- `s` argument is a math expression with flag names, parentheses, arithmetic and memory brackets; `s $$+4` equals `s+4`; registers work as flags (`s rsp+0x40`); pointer deref command `*` honors `asm.bits` and `cfg.bigendian` — https://book.rada.re/commandline/seeking.html — 2026-11-17 — primary.
- Source parser: `0x` and `0X` both accepted (`tolower(str[1])=='x'`); `0b`, `0o`, `0t` prefixes; trailing `h`/`o`/`b`/`t` suffixes; leading `0` plus digit treated as octal unless trailing suffix is `b` or `h`; trailing `u`/`U` allowed on hex; underscores allowed in hex — https://github.com/radareorg/radare2/blob/master/libr/util/unum.c — 2026-11-17 — primary.
- Local 6.2.2 `?vi` check: `0x10` and `0X10` -> 16, `077` -> 63, `1010b` -> 10, `10h` -> 16, `10o` -> 8, `0o17` -> 15, `1K` -> 1024, `1M` -> 1048576, `0x10+2` -> 18, `entry0` -> 22384, `main` -> 13728 — local binary probe (no URL) — 2026-11-17 — primary (observed).
- Flag prefixes from source: `symbol_flag_prefix()` returns `sym.imp` for imports, else `sym`; `aa` runs `af @@ sym.*;af@entry0;afva` — https://github.com/radareorg/radare2/blob/master/libr/core/cbin.c and https://github.com/radareorg/radare2/blob/master/libr/core/cmd_anal.inc.c — 2026-11-17 — primary.
- Local 6.2.2 flag listing contains `fcn.000057a0`, `section..text`, `sym.error`, `reloc.fcntl`; `entry0` is referenced directly in source — https://github.com/radareorg/radare2/blob/master/libr/core/cfile.c — 2026-11-17 — primary.
- Config definitions: `asm.bits` (word size in bits at assembler, default from sysbits) and `cfg.bigendian` (little=false, big=true) — https://github.com/radareorg/radare2/blob/master/libr/core/cconfig.c — 2026-11-17 — primary.

### 2. Failure modes for unknown symbol/address

- `Invalid tmpseek address '%s'` at cmd.c:5582 and `Invalid command '%s' (0x%02x)` at cmd.c:6649 — https://github.com/radareorg/radare2/blob/master/libr/core/cmd.c — 2026-11-17 — primary.
- Local 6.2.2 exact output for `pd 2 @ sym.zzz_no_such_symbol` and `aflj @ sym.zzz_no_such_symbol`: two stderr lines `ERROR: Invalid tmpseek address 'sym.zzz_no_such_symbol'` then `ERROR: Invalid command '...' (0x70)` / `(0x61)`; stdout empty; CLI exit code 0 — local probe + source above — 2026-11-17 — primary (observed).
- `unknown symbol` error originates in RNum (`error (num, "unknown symbol")`, unum.c:462); local `?v sym.zzz_no_such_symbol` -> stderr `ERROR: unknown symbol`, stdout `0x0`, exit 0 — https://github.com/radareorg/radare2/blob/master/libr/util/unum.c — 2026-11-17 — primary.
- Other literal errors: `Cannot find function in 0x%08x`, `Cannot find function`, `Cannot find a name for this address` (cmd_anal.inc.c); `Cannot find flag '%s'` (cmd_flag.inc.c:1776); `Cannot find function here` (cmd_meta.inc.c:1651) — https://github.com/radareorg/radare2/tree/master/libr/core — 2026-11-17 — primary.
- r2pipe `cmdj()` maps empty stdout to `{}` before `json.loads`; invalid JSON writes `r2pipe.cmdj.Error: ...` to stderr and returns `None`; `cmdJ()` returns `None` on parse error — https://github.com/radareorg/radare2-r2pipe/blob/master/python/r2pipe/open_base.py — 2026-11-17 — primary.
- Local 6.2.2: stdout of `aflj @ sym.zzz_no_such_symbol` is zero bytes, so r2pipe `cmdj("aflj @ sym.zzz_no_such_symbol")` returns `{}`, not `[]` — local probe + r2pipe source — 2026-11-17 — primary (observed + source).
- r2pipe spawn translates stdin newlines to `;`, raises `RuntimeError` if the r2 process dies mid-command and `ConnectionError` if the pipe closes before NUL terminator — https://github.com/radareorg/radare2-r2pipe/blob/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.

### 3. Headless/noninteractive flags (official man page)

- `-q` quiet, no prompt, quit after `-i`/`-c`; `-qq` quit right after evaluating `-e`, `-c`, `-i`; `-Q` same but skip RCore free (faster, leaks) — https://github.com/radareorg/radare2/blob/master/man/radare2.1 — 2026-11-17 — primary.
- `-2` close stderr before starting RCore; `-0` emit NUL after init and every command; `-1` redirect stderr to stdout; `-c cmd` execute command before prompt; `-e k=v` set eval var (example `-e scr.color=false`) — https://github.com/radareorg/radare2/blob/master/man/radare2.1 — 2026-11-17 — primary.
- `-n` do not perform r_bin analysis, load raw file; `-nn` only load rbin structures; `-N` do not load user settings/projects from rc files and rc.d scripts; `-NN` also disable plugin autoload — https://github.com/radareorg/radare2/blob/master/man/radare2.1 — 2026-11-17 — primary.
- `-a arch` force asm.arch; `-b bits` force asm.bits (16/32/64); `-m addr` map file at given address; `-B baddr` base address for PIE; `-s addr` initial seek; `-w` open in write mode — https://github.com/radareorg/radare2/blob/master/man/radare2.1 — 2026-11-17 — primary.
- Book example: `r2 -q -c 'p8 10 @ entry0' /bin/ls` — quiet + `-c` returns straight to shell; `r2 -qc ij hi.bin` for JSON output — https://book.rada.re/first_steps/commandline_flags.html — 2026-11-17 — primary.
- r2pipe always spawns `[radare2, "-q0", filename]` with `flags` inserted between the executable and `-q0` — https://github.com/radareorg/radare2-r2pipe/blob/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.

### 4. `-A` auto-analysis

- Official man: `-A` runs `aaa` before prompt/patch to analyze all referenced code; `-AA` runs `aaaa` — https://github.com/radareorg/radare2/blob/master/man/radare2.1 — 2026-11-17 — primary.
- Source `perform_analysis()` maps analysis level: 0 -> empty command, 1 -> `aa`, 2 -> `aaa`, 3 -> `aaaa` (default command string `aaaaa`) — https://github.com/radareorg/radare2/blob/master/libr/main/radare2.c — 2026-11-17 — primary.
- `aaa` = deeper analysis, most common; `aaaa` adds experimental iterations; `aaaaa` refines after `aaaa`. `aa` is alias for `af @@ sym.*;af@entry0;afva`; lighter alternatives: `aac` (calls), `aas` (symbols, `af @@= isq`), `afl` only lists functions, no analysis — https://github.com/radareorg/radare2/blob/master/libr/core/cmd_anal.inc.c — 2026-11-17 — primary.
- `anal.autoname` exists with default `false` ("speculatively set a name for the functions, may result in some false positives"); `anal.symsort` default 0 — https://github.com/radareorg/radare2/blob/master/libr/core/cconfig.c — 2026-11-17 — primary.
- Cost: no primary source quantifies runtime; describe as whole-program recursive analysis, not a fixed number — 2026-11-17 — primary (absence of quantified claim).

### 6. Windows support

- Official book: prebuilt Windows binaries on releases page; native build uses Meson+Ninja+Visual Studio 2019+ via `preconfigure.bat`, `configure.bat`, `make.bat`; Cygwin/acr builds unsupported; MinGW cross build via `sys/mingw32.sh` — https://book.rada.re/install/windows.html — 2026-11-17 — primary.
- r2pipe spawn on Windows appends `.exe` to `radare2`, uses `Popen(..., shell=False, stdin=PIPE, stdout=PIPE)`, and reads the initial NUL byte twice (spawn quirk); `hello_cmd` probe is skipped on Windows — https://github.com/radareorg/radare2-r2pipe/blob/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.
- When r2pipe runs INSIDE r2 on Windows, it uses a named pipe: env `r2pipe_path`, `CreateFileW`, `ERROR_PIPE_BUSY` retry with `WaitNamedPipeW(..., 20000)`, then `WriteFile`/`ReadFile` on the handle; on POSIX the same path uses numeric `R2PIPE_IN`/`R2PIPE_OUT` fds — https://github.com/radareorg/radare2-r2pipe/blob/master/python/r2pipe/open_base.py — 2026-11-17 — primary.
- Path handling: `normalize_open_target()` splits a string filename on spaces into target plus extra args unless URI scheme; accepts list/tuple as (target, args); `os.fsdecode` coercion — https://github.com/radareorg/radare2-r2pipe/blob/master/python/r2pipe/open_base.py — 2026-11-17 — primary.
- Missing-binary errors: `FileNotFoundError("ERROR: Cannot find radare2 in PATH")`, `IOError("radare2 can't be found in your system")`, `EnvironmentError("ERROR: Cannot use #!pipe without R2PIPE_{IN|OUT} env")` — https://github.com/radareorg/radare2-r2pipe/blob/master/python/r2pipe/open_sync.py and open_base.py — 2026-11-17 — primary.
- Cancellation (async client): canceling a started command lets its response finish draining before next command; the command may still change radare2 state; closing waits for started commands and rejects queued ones — https://github.com/radareorg/radare2-r2pipe/blob/master/python/README.md — 2026-11-17 — primary.

### 8. Source-file mutation

- Default file permissions are `R_PERM_RX` (read+execute, no write); `-w` sets `mr.perms |= R_PERM_W` — https://github.com/radareorg/radare2/blob/master/libr/main/radare2.c — 2026-11-17 — primary.
- Man page: `-w` = open in write mode; `-c` commands run without it do not get write permission — https://github.com/radareorg/radare2/blob/master/man/radare2.1 — 2026-11-17 — primary.
- `io.cache` default `false` (changes both `io.cache.read` and `io.cache.write`); `io.cache.write` default `true` once cache enabled — https://github.com/radareorg/radare2/blob/master/libr/core/cconfig.c — 2026-11-17 — primary.
- `w?` help confirms mutation commands: `w` string, `wX` cyclic hex, `wx` hexpairs, `wa` assemble+write, `waf`/`waF` from file, `wf` copy file, `wt[afs]` write to file, `wv` write 1/2/4/8-byte using `cfg.bigendian`, `wc[jir+-*]` cache list/undo/commit/reset — local `r2 -c 'w?'` probe 2026-11-17 — primary (observed).
- No `cfg.write` eval var exists; write capability is process/file-open state (`-w`) plus io cache, not an eval flag — cconfig.c + local `e cfg.write` empty — 2026-11-17 — primary.

## Conflicting evidence

- Shared-team note says `fcn.0x...`; current 6.2.2 emits `fcn.000057a0` (no `0x` prefix). Use observed form; old form unverified for current release.
- Secondary r2wiki says projects in HOME/.config/radare2/projects; primary book and source say XDG data home, default HOME/.local/share/radare2/projects. Prefer primary.
- Man page lists `R2_RDATAHOME`, source help lists `R2_DATA_HOME`; environment variable naming changed between versions; do not depend on either for project path.
- `e cfg.project` / `e cfg.write` appear in team shared facts but are not config keys in source or local 6.2.2; use `prj.name` and process write mode instead.
- Invalid address via `@ 0xZZZ` silently parses to 0 on 6.2.2 (disassembly at 0) instead of erroring; invalid named symbol errors. Do not assume validation rejects all malformed numerics.
