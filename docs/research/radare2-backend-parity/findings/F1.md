Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_sync.py ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_async.py ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py — 2026-11-17 — primary.
- FACT: Local spawn builds `[r2e, "-q0", filename]` then `cmd = cmd[:1] + flags + r_args + cmd[1:]`, i.e. invocation is `radare2 -q0 <caller flags> <target>`. `r2e` = `<radare2home>/radare2` when `radare2home` given else literal `radare2` (plus `.exe` on Windows). r2pipe always injects `-q0`; do not pass it again. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.
- FACT: `normalize_open_target()` accepts a list/tuple whose first element is the target and rest become extra r2 args encoded as `-Rarg{i+1}=<arg>`; a single string with spaces is also split into target + args (except http/tcp/ccall/pipe targets). ### 3. `cmd()`, `cmdj()`, variants

- FACT: `cmd(self, cmd, **kwargs) -> str`. Sync `_cmd_process` strips command, replaces newline with `;`, writes `cmd + "\n"` to stdin, reads stdout until NUL (`\x00`) terminator, decodes UTF-8 with `errors="ignore"`. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.
- FACT: `cmdj(cmd, **kwargs)` = `cmd()` then `json.loads`. Empty string is coerced to `"{}"` → returns `{}`. On `ValueError`/`KeyError`/`TypeError` it writes `r2pipe.cmdj.Error: <e>` to stderr and returns `None`. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py — 2026-11-17 — primary.
- FACT: `cmdJ()` parses via `jo2po` into namedtuples; on parse error writes same stderr message and returns `None` (no empty-string coercion). Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py — 2026-11-17 — primary.
- FACT: `cmd2()`/`cmd2j()` (r2pipe2) send `"'" + json.dumps({"cmd": cmd, "trim": bool, "json": bool})`, accept `callback=`, return `SimpleNamespace` tree; `cmd2j` defaults `trim=True, json=True`. Unknown options/non-bool flags/non-callable callback raise `TypeError` before execution. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/README.md ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py — 2026-11-17 — primary.
- FACT: `call(cmd, *, callback=None)` prefixes `'` to cmd. `syscmd(cmd)` runs `Popen(cmd, shell=True, stdin=PIPE, stdout=PIPE)` and returns raw bytes stdout; `syscmdj()` JSON-parses that or returns `None` on error with stderr `r2pipe.syscmdj.Error`. No `cmdv` method. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py — 2026-11-17 — primary.
- FACT: Async client exposes awaitable `cmd`, `cmdj`, `cmdJ`, `call`, `cmd2`, `cmd2j` when a loop is running; same methods block outside a loop. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/README.md ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_async.py — 2026-11-17 — primary.

### 4. `quit()`, one instance per worker, concurrency

- FACT: `OpenBase.quit()` — if `.process` exists, close `stdin`/`stdout`, call `process.terminate()`, `process.wait()`, then `delattr(self, "process")`. Source comment: `# HANGS self.cmd("q!!")`. No `q!!` command is sent. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py — 2026-11-17 — primary.
- FACT: Sync `open` is a context manager: `__enter__` returns self, `__exit__` calls `quit()` and returns False. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.
- FACT: Sync local-process transport holds `self._cmd_lock = threading.Lock()` and wraps the entire `_cmd_process` exchange in `with self._cmd_lock:`. Commands on one object are serialized, not interleavable; no concurrent command multiplexing on a single object. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.
- FACT: Sync `#!pipe`, HTTP and TCP transports have no such lock in current source; embedded pipe path in `open_base.py` also has none. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.
- FACT: Async client serializes with `asyncio.Lock`; README states "Commands on one client run in sequence, including commands submitted with `asyncio.gather`". Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/README.md ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_async.py — 2026-11-17 — primary.
- DESIGN IMPLICATION (inference from above): use exactly one r2pipe object per worker process; do not issue two commands on it expecting concurrent results. Source: same as above — 2026-11-17 — primary facts, speculative design conclusion.
- FACT: Dead-process detection: sync `_cmd_process` raises `RuntimeError("Process terminated unexpectedly ...")` if `process.poll()` is not None, and `ConnectionError("r2pipe connection closed before response terminator")` if stdout closes before NUL. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.

### 5. Async / interrupt / cancellation

- FACT: Async client cleanup: `async with`, or `await r2.close()` / `await r2.quit()`; closing keeps caller's event loop open; `aclose()` shields shutdown task against repeated cancellation. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/README.md ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_async.py — 2026-11-17 — primary.
- FACT: Cancellation semantics — source comment "A canceled caller must not interrupt reading a command's response"; implemented with `await asyncio.shield(task)`. If canceled before start, `task.cancel()`; if already started, response is drained before next command. README: "the command may still change radare2 state. Closing waits for these started commands and rejects commands still waiting to run." Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_async.py ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/README.md — 2026-11-17 — primary.
- FACT: No user-facing `timeout=` parameter on `cmd`/`cmdj`/`cmdJ`/`call`/`cmd2`/`cmd2j`. `cmd(cmd, **kwargs)` forwards kwargs; sync `_cmd_process(self, cmd)` takes no kwargs, so `cmd(..., timeout=N)` raises `TypeError`. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_sync.py — 2026-11-17 — primary.
- FACT: Only internal timeouts: async HTTP header `wait_for(..., timeout=10.0)`, body reads `timeout=5.0`; async TCP first read `timeout=10.0`, subsequent reads `timeout=1.0`; on timeout closes connection and raises `TimeoutError("Timeout while reading HTTP response")` / `TimeoutError("Timeout while reading TCP response")`. Not configurable. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_async.py — 2026-11-17 — primary.
- FACT: No signal/interrupt handling in r2pipe source (searched `signal`, `interrupt`, `kill`, `cancel`, `timeout`, `terminate` across package): only sync `terminate()` on quit and async `terminate()` then `kill()` after a 1.0s `wait_for`. OS-level SIGINT/kill of the spawned r2 is external. Source: https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_sync.py ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_base.py ; https://raw.githubusercontent.com/radareorg/radare2-r2pipe/master/python/r2pipe/open_async.py — 2026-11-17 — primary.
- FACT: radare2 `-q` sets `cfg.fortunes=false`; no command-execution timeout config appears in r2 main help. Source: https://raw.githubusercontent.com/radareorg/radare2/master/libr/main/radare2.c — 2026-11-17 — primary for cfg.fortunes; absence of timeout config verified only in that file.
